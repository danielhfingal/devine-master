# captures/

Loopback / import landings for SourceCast.

Naming: `YYYYMMDD_HHMM_source_capture.<ext>`

Typical flow (Suno):
1. Play the Suno result in the browser (or app).
2. Run `tools/capture_loopback.py` on F: (see tools/README).
3. File appears here → load into DEVINE MASTER (SourceCast A) → master.

Do not put release masters here — use your mastered vault.
